Esta carpeta contiene el programa determinista de bancos positivos y negativos del trabajo **Distancia absoluta y relativa entre observables del Universo**.

## Archivos

| Archivo | Función |
|:---|:---|
| `lab_bancos_negativos.py` | Ejecuta la batería completa de casos. |
| `salida_esperada.txt` | Resume la salida esperada. |
| `salida_obtenida.txt` | Recoge la salida obtenida al ejecutar el laboratorio. |

## Ejecución

```bash
python lab_bancos_negativos.py
```

## Criterio de aptitud

La batería queda superada únicamente si se cumplen simultáneamente dos condiciones: los seis positivos reciben `APTO` y los quince negativos reciben `NO_APTO` con la compuerta esperada. Esa doble condición impide el pase silencioso.
