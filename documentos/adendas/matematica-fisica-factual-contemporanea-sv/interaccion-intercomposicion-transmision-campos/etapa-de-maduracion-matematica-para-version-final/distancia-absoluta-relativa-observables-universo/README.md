## Ejecución de laboratorios

Desde la carpeta `laboratorios/`:

```bash
python lab_bancos_negativos.py
```

El laboratorio debe aceptar 6/6 positivos, rechazar 15/15 negativos por la compuerta correspondiente y emitir el dictamen `BATERÍA SUPERADA`.
