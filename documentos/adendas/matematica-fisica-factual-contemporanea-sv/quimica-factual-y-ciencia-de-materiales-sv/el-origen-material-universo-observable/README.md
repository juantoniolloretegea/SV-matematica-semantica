## Presentación

Esta publicación estudia el origen material ordinario del universo observable como problema de tránsito entre dominios físicos, no como enumeración cosmológica, química o biológica. El desarrollo separa condición preformal, activador primero, espacio, materia ordinaria y continuidad material posterior, de modo que el régimen H–He se sitúa en su plano propio: primera organización material ordinaria, no fundamento absoluto, no espacio, no `ε₋₀` y no `ε₀`.

La tesis articula hidrógeno, helio, referencia solar, tabla periódica estructural, catálogo SV-443, Catálogo de Pares Estructurales SV, moléculas y continuidad biológica bajo dominio, frontera, residual, retorno y contraste físico. El documento mantiene la distinción entre materialidad ordinaria retornada, capacidad estructural, sutura gravitatoria efectiva y residual de no clausura.

## Laboratorio BCAM-HHe

El Banco de Contraste de Admisibilidad Material H–He (`BCAM-HHe`) acompaña el cuerpo principal como laboratorio reproducible de consistencia formal y ejecución de matriz. Su función es comprobar que la matriz de admisibilidad discrimina correctamente admisiones, defectos, no determinaciones legítimas y salidas específicas del CPS-SV.

Resultado de referencia del banco:

- 25 casos ejecutados.
- 25 coincidencias entre salida esperada y salida obtenida.
- 0 divergencias.
- Veredicto global: `APTO`.

Ejecución de referencia:

```bash
python laboratorios_BCAM-HHe/scripts/runner_bcam_hhe.py \
  --cases laboratorios_BCAM-HHe/datos/bcam_hhe_casos.csv \
  --out laboratorios_BCAM-HHe/salidas/bcam_hhe_salidas_obtenidas.csv
```
