# Potencial de un suceso: comunicación estructural en el Universo físico realizado, equipotencialidad, diferencia polar y métrica

Esta publicación formula el potencial de un suceso como magnitud estructural de separación polar dentro de un dominio declarado. El desarrollo distingue origen formal, equilibrio realizado, potencial local, intensidad, diferencia entre sucesos, identidad, traza, métrica tipada, transducción por dominios y comunicación estructural sin sintiencia.
